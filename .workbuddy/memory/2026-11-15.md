# 2026-11-15 Savor 主题工作记录

## 新增 Linen（亚麻）浅色阅读配色
- 需求：`增加浅色的配色，高级，适合阅读，舒适`。
- 设计：米白纸面 `#f6f4ef` + 暖深灰正文 `oklch(34% .012 78)` + 低饱和灰蓝主色 `oklch(50% .045 243)`；
  面板 `0.935` / 代码块 `0.949` / 纸面 `0.964` 三级亮度递进；顶栏与 dock 激活态由默认高饱和橙红
  `oklch(68.98% .161 30.76)` 换成灰蓝；行内代码、搜索高亮、13 个标注底色统一降饱和。
- 涉及文件：
  - 新建 `style/theme/savor-linen.css`（作用域 `:root[data-theme-mode="light"][savor-theme="linen"]`，含三组标签栏 SVG 圆角色与 `body::before{display:none}`）
  - `theme.css` 在 Wind 之后、Dark 之前加 `@import`
  - `js/modules/buttons.js` 在 light 组末尾加 `buttonlinen` / `Sv-theme-color-linen`
  - `i18n/{zh_CN,zh_CHT,en}.json` 加 `"Linen 配色": "Linen"`
  - `README_zh_CN.md` 配色清单补一条
- 接入规律（可复用）：新增配色 = 新建 CSS + theme.css @import + buttons.js 的 light/dark 组按钮 + 三语言 i18n + README；
  `themeSetting.js` 靠 `group` 过滤、`styleId` 记忆，无需改动；`updateColorfulHeading` 仅对 sugar/flower 生效。
- 构建：`npm run build` 通过（esbuild + lightningcss 平台依赖已在 11-09 补齐）。注意 esbuild 会把中文文案
  转义成 `\u914D\u8272`，grep `"Linen 配色"` 查不到属正常，应查 `buttonlinen`。
- 验证方式：无头 Chrome 内联 `dist/theme.css`，切换 `savor-theme` 后读 computed 自定义属性并用 canvas 转 RGB。
  结果：正文/纸面对比度 **10.75:1**（AAA 且非纯黑刺眼）；七套浅色配色互不干扰；
  Wind 的 `body::before` 仍为 `block`，其余为 `none`；`data-theme-mode=dark` 下 linen 作用域不生效。
- 已知小瑕疵：light 组配色按钮从 6 个变 7 个，工具栏 `repeat(2,1fr)` 网格末行会留一个空位；未调整布局。
