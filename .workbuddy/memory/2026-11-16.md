## MacOS 深浅配色支持思源「背景渐变」
- 需求与截图：思源设置里「背景渐变 → 自动（根据工作空间名称）」已开启，但 macOS 配色下看不到渐变。
- 机制：思源在 `body` 上定义 `--b3-window-background-image: var(--b3-body-background-gradient, radial-gradient(…hsla(var(--b3-body-background-hl), calc(--b3-body-background-hl-opacity*0.5))…))` 并
  `background-image: var(--b3-window-background-image)`；设置面板的自动/自定义渐变写入 `--b3-body-background-gradient`。
  Savor 在 `theme.css` 里有一条全局 `body { background-image: unset }` 把它关掉了。
- 修复（仅 macOS 配色）：`savor-macos.css` 浅/深两个作用域块各加
  `body { background-image: var(--b3-window-background-image); }`（嵌套在配色块里，压缩后为 `:root[…] body`，
  特异性高于全局 unset）；同时覆盖 `--b3-body-background`（画布=纸面色）、`--b3-body-background-hl`（浅 `211,100%,50%` /
  深 `212,100%,52%`，即 systemBlue 的 HSL）与 `-hl-opacity`（浅 0.16 / 深 0.3）作为自动模式未设置时的回退光晕。
- 验证坑：无头 Chrome 测试页若只内联 Savor CSS，`--b3-window-background-image` 未定义，computed 为 none，
  会得出假阴性；必须把思源 `body{--b3-window-background-image:…}` 原生规则一并内联。
- 结果：macOS 浅/深显示 systemBlue 径向光晕（rgba(0,123,255,·) / rgba(10,124,255,·)），画布 = 纸面色；
  设置自定义/自动渐变后正确透传；其他 16 种配色组合保持 `none` 不受影响。构建通过（CSS 283.5 KB）。
- 若以后要给其他配色开渐变，复制这三行变量 + 一条 body 规则即可；hl 用该配色强调色的 HSL。

## 四套配色页签透明
- 需求（附 XPath `#layouts … ul.layout-tab-bar > li`）：white、macos、vscode、nord 深浅配色下页签 li 背景改为 transparent。
- 页签底色来源（思源 base.css）：hover `.item:hover:not(.item--focus):not(.item--readonly)` = `--b3-theme-surface`、
  focus `.item--focus` = `--b3-theme-surface-light` + 内边框、窗口激活 `.layout__wnd--active .item--focus` = `--b3-theme-primary-lightest`；
  未激活 li 本身无背景。Savor 融合模式另有 `--Sv-tab-bar-item-background-focus`（= 编辑区背景）。
- 实现：white(1) + macos/nord/vscode(各2) 共 7 个作用域块内嵌套一条规则：
  `.layout-tab-bar .item, .item:hover…, .item--focus, .layout__wnd--active .item--focus { background-color: transparent }`。
  嵌套编译为 `:root[mode][theme] …`，特异性高于原生（focus 0,3,1 vs 0,2,1；wnd-active 0,4,1 vs 0,3,1），
  且主题 CSS 后于 base.css 加载，融合模式规则 (0,8,1) > Savor (0,8,0)。
- 验证：8 个作用域下 li/focus/窗口激活 focus 全部 transparent；light/dark 默认配色保持原生底色不受影响。
  页签的 inset 边框（focus 的 box-shadow）保留，激活页签仍可辨识。构建通过（CSS 288.0 KB）。
- 激活页签只透明了背景、保留了边框；若用户后续想要"完全无边框"需再覆盖 box-shadow。
